# HTMLS

Static HTML files for GitHub hosting.

## Ready for HTML uploads

This repository now includes:

- `/index.html` as a landing page
- `/.nojekyll` so GitHub Pages serves files directly without Jekyll processing

## How to use it

1. Upload your `.html` files and any related assets to this repository.
2. In GitHub, open **Settings → Pages**.
3. Set the site to deploy from the `main` branch and the `/ (root)` folder.
4. Open your uploaded pages from:

   - `https://scriptb.github.io/HTMLS/`
   - `https://scriptb.github.io/HTMLS/your-file.html`

If you add more pages, update `/index.html` with links to them so they are easy to open from the site homepage.
